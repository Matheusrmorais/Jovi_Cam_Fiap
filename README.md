## 📖 Sobre o projeto

O **JOVI Cam** é uma plataforma educacional voltada para pessoas que desejam aprender mais sobre fotografia de maneira prática, visual e acessível.

A proposta é apresentar diferentes situações fotográficas e auxiliar o usuário na escolha das melhores configurações e técnicas para cada ambiente.

O projeto foi desenvolvido com foco em **experiência do usuário, organização visual, interatividade e responsividade**, utilizando tecnologias web modernas.

---

## 🎯 Objetivo

O objetivo do JOVI Cam é facilitar o aprendizado de fotografia por meio de uma experiência interativa.

A plataforma apresenta diferentes ambientes e situações, permitindo que o usuário explore conteúdos específicos e encontre dicas adequadas ao seu nível de conhecimento.

### 📷 Ambientes disponíveis

* 🌙 Ambiente Noturno
* ☀️ Ambiente Claro
* 🏠 Ambiente Interno
* 🚶 Ambiente Movimentado
* 🌧️ Ambiente Chuvoso
* ⚙️ Ambiente Personalizado

## 💡 Funcionalidades

### 🏠 Home

Página inicial responsável por apresentar a proposta do JOVI Cam e direcionar o usuário para os principais recursos da plataforma.

### 📚 Dicas de fotografia

Conteúdos organizados por nível de conhecimento:

* 🟢 Iniciante
* 🟡 Intermediário
* 🔴 Avançado

As dicas abordam diferentes aspectos da fotografia e ajudam o usuário a evoluir gradualmente.

### 🎥 Conteúdo em vídeo

O projeto utiliza vídeos curtos para demonstrar situações e técnicas fotográficas de maneira visual e prática.

### 📸 Ambientes fotográficos

O usuário pode explorar diferentes cenários e encontrar informações específicas para cada situação.

### 🐾 Sistema de gamificação

A experiência conta com elementos de gamificação, como:

* Mascote
* Recompensas
* Perfil
* Ranking

Esses elementos foram pensados para tornar o aprendizado mais interativo e incentivar a evolução do usuário.

### 📱 Interface responsiva

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela, proporcionando uma experiência consistente em computadores e dispositivos móveis.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Matheusrmorais/Jovi_Cam_Fiap.git
```

### 2. Acesse a pasta

```bash
cd Jovi_Cam_Fiap
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

Abra o projeto no **Visual Studio Code** e utilize um servidor local, como o **Live Server**.

## 🧩 Conceito

O JOVI Cam foi pensado para transformar o aprendizado de fotografia em uma experiência mais **visual, interativa e acessível**.

Em vez de apresentar apenas conteúdos teóricos, a plataforma utiliza:

**Ambientes → Dicas → Exemplos → Prática → Evolução**

Dessa forma, o usuário consegue relacionar o conteúdo aprendido com situações reais de fotografia.
